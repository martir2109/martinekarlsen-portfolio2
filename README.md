## 🛠️ Technologies stack

- React
- React router dom
- Tailwind CSS
- JavaScript
- Vite (development server)
- Lucide react (icons)
- EmailJS (contact form)
- React icons (GitHub icon)

## ✨ Features

- Responsive design for mobile and desktop
- Project pages with descriptions, live demos, and GitHub links
- Contact form powered by EmailJS
- Smooth navigation with React Router

## Getting Started

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/martir2109/martinekarlsen-portfolio2.git
cd martinekarlsen-portfolio2
npm install
```

### Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

### Build for production

```bash
npm run build
```
